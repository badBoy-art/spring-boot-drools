3规则类型 —— 按「单据对象/字段 + 接口」生成规则模板（不用写 Java、不用重启）

规则类型 = 一条 DRL 模板 + 一组可填参数。研发在「接入配置台」登记好单据字段和接口后，运营在这里选单据、判定字段、运算符、动作，点「生成模板」看生成的 DRL，确认后「保存规则类型」。
判定字段和运算符是下拉选出来的（直接写进模板，避免手打错路径）；模板体由系统按白名单拼装、页面只读 —— 要新动作或自定义 DRL 请找研发。

6组合规则表 —— 多条件组合在页面上填表格（全页面配置，不涉及 Excel）

一张表 = N 个条件列 + 1 个动作 + N 行组合；每行编译成一条规则，整张表一次发布（改完即生效）。
数据只存在库里：页面表格 → 校验 → 生成 DRL 文本存库 → 引擎直接编译 DRL，全程没有 Excel 文件的产生或上传。
取值列有下拉/白名单/数字校验，报错定位到"第几行哪一列"；动作白名单：改金额 / 打标 / 加消息 / 调接口。
