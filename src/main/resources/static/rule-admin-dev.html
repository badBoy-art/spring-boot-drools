接入配置台 —— 研发维护区

生效规则 - 已发布 - ↗ 规则运营台（产品/运营）
本页职责：① 单据注册（单据 → 对象 → 字段，含派生表达式） → ② 接口注册（域名 / 入参模板 / 返回值映射 / 认证 / 加解密 / 签名，密钥只存引用名）
⚠ 这里是"技术契约"层：字段路径、密钥引用、算法白名单改错会影响所有规则。业务取值的日常维护请去「规则运营台」。
① 单据注册 ② 接口注册 两个独立注册入口，互不依赖：各自注册一次，被多个单据 / 多条规则引用（一处注册，多处调用）。地址：#doc / #action 可直达

1单据注册 —— 注册单据对象信息（单据 → 单据对象(可嵌套) → 对象字段）

这一步只登记"这个单据有哪些对象、每个对象有哪些字段、字段中文名叫什么、怎么取值"。登记完，配接口入参/规则参数时就能直接从下拉里挑，不用手打路径。
字段取值路径支持三种写法：对象属性 totalAmount、嵌套/数组 customer.level、items[0].product.category、方法 items.size()。
单据列表对象与字段（点字段复制 ${fieldName}）被引用（一处注册，多处调用）

2接口注册 —— 规则命中后要调用的 HTTP 接口（域名/入参/返回值/认证/加解密都可配）

只支持原生 HTTP，不引 Feign、不引各业务线 SDK。接口按业务场景分类：单据接口 / 流程引擎接口 / 风控接口 / 其它。
入参模板三种写法混用：常量 "channel":"规则引擎"、对象属性 "${customer.level}"、计算值 ${totalAmount * 0.01}；
返回值按映射回填单据的 ext，后续规则可用 ext["riskLevel"] == "HIGH" 继续判定。
接口列表（按分类）请求返回值映射适用范围 / 被引用操作

新建 / 覆盖 接口（动作码是主键，同一个就覆盖）

接口是独立资产：留空 = 任何单据的规则都能调它（通用）；多选 = 限定范围。同一个接口可被多个单据、多条规则引用，只在"使用点"（③ 规则类型 / ④ 规则 / ⑥ 组合表）建立调用关系。
密钥真值不在这里填，只填引用名；真值放 application.yml 的 rule-http.secrets。
